# MiddleClick AutoRun

Dalamud（卫月）插件，API 15。中键开关前进：按一下一直走，再按一下停，放技能不打断。

前进方式就是按住游戏的鼠标左右键（原生前进），用技能不会打断它，所以不需要任何「补回 / 重新开启」。

## 安装

`/xlplugins` → 设置 → 自定义插件仓库 → 添加：

```
https://raw.githubusercontent.com/wucan-wen/MiddleClickAutoRun/main/pluginmaster.json
```

刷新后安装「MiddleClick AutoRun」。（若之前用开发者模式装过，先把那份停用，同 InternalName 会冲突）

> **键位提示**：如果你的游戏「键位设置」里已经把「自动前进」绑成了鼠标中键，请先改成别的键或清空。
> 插件本身就是用中键做开关，两边同时生效会互相抢状态，表现为按一下停一下。

## 使用

| 动作 | 行为 |
| --- | --- |
| 按鼠标中键 / 窗口「开始」 | 开始保持前进（按住左键 + 右键） |
| 再按中键 / 窗口「停止」 | 立刻松开停止 |
| 按 W/A/S/D | 立刻松开并停止（视为你要自己走） |
| 使用位移技能 | 立刻松开并停止 |
| 走到当前目标判定距离内 | 立刻松开并停止（只有靠近才触发，远离不拦） |

- 不注册聊天命令，也不往聊天框输出任何提示
- 设置窗口：插件列表里本插件的设置按钮（齿轮）

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 到达目标附近就停止 | 开 | 靠近当前目标到判定距离即停 |
| 停止距离 | 2.0 米 | 按水平距离算 |
| 使用位移技能时停止 | 开 | 技能动作中瞬时速度超过判定速度即停 |
| 位移判定速度 | 15 米/秒 | 跑步约 4~6，坐骑约 20 |
| 继续原有面向 | 关 | 技能动作期间压住朝向，避免被技能带着拐弯 |

## 实现方式（规范相关）

- 不用 Harmony 钩子、不写游戏内存里的逻辑状态。
- 读：`ConditionFlag.Casting`（是否施法）、`ActionManager.AnimationLock`（动画锁）、
  `InputManager.GetInputStatus(MOVE_*)`（移动输入）、玩家位置与朝向。
- 写：`mouse_event` 发送鼠标左/右键按下与松开（复现原生「左右键同按 = 前进」），
  以及技能动作期间 `GameObject.SetRotation` 压回朝向（仅在「继续原有面向」开启时）。
- `Dispose` 时松开按键并解绑所有事件与字体句柄。

## 构建

```
build.cmd
```

产物在 `AutoRunKeeper\bin\x64\Debug\`，脚本会复制到 `..\..\devPlugins\AutoRunKeeper\`。
